# twl-hs-interns-notebooks

Teaching materials for KU Trade War Lab intern programs.

| Folder | Program | Format |
|---|---|---|
| [`hs-interns/`](hs-interns/) | Summer '26 high school interns | Four async notebooks (edit-the-parameters style). See `hs-interns/README_week1_notebooks.md`. |
| [`ku-interns/`](ku-interns/) | KU econ / poli sci interns | One-hour live session: Python in Colab with AI assistance, then an R homework in RStudio. See `ku-interns/README.md`. |

Each folder is self-contained: its notebooks load data from that folder's own `data/`
via `raw.githubusercontent.com` URLs on `main`.
